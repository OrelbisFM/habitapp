# HabitHero

HabitHero is an Android habit tracker assignment built with Java & Room. Create habits, set how often they should be done, and check them off each day to build a streak.

## Features

- **Create habits** with a title, optional note, and frequency (Daily, Weekdays, Weekends)
- **Track streaks** - checking off a habit on consecutive days increments your streak; missing a day resets it
- **Swipe management** - long press a habit to delete it
- **Local storage** via Room, so your habits and streaks survive app restarts

### Build & Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Let Gradle sync and download dependencies.
4. Run the app on an emulator or physical device (`Run ▶`).
